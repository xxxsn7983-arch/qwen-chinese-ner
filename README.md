# 基于 Qwen 与 LoRA 的中文命名实体识别实验

基于 Qwen2.5-0.5B-Instruct，在 CLUENER 数据集上开展生成式中文命名实体识别实验。

## 实验版本

- v2：基础 LoRA 微调配置。
- v4：最终发布版本，探索监督策略与训练配置调整。
- v5、v6：进一步的训练配置与数据采样探索。
- experiments/bio：BIO 序列标注探索，未作为最终发布方案。

## 已记录的验证结果

| 版本 | Precision | Recall | F1 |
| --- | --- | --- | --- |
| v2-weak | 0.6174 | 0.6127 | 0.6150 |
| v2-strong | 0.6268 | 0.6184 | 0.6226 |
| v4 | 0.6730 | 0.2968 | 0.4119 |

以上数值来自项目报告。
v2 的原始评估记录及各版本效率数据有待补充。

## 文件说明

- train_v*.py：各版本训练脚本。
- dataset.py：训练数据构造。
- convert.py：数据格式转换。
- inference*.py：测试集与验证集推理。
- eval_val.py：验证集评估。
- eval_outputs/：评估指标、图表和错误案例。
- report.pdf：技术报告。

## 复现说明

依赖见 requirements.txt。
运行前需获取 CLUENER 数据，并根据脚本配置数据与模型路径。
当前脚本包含本地路径，尚需调整才能在其他环境直接运行。
